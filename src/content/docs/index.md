DiceScript Next 规定一种面向 TRPG 命令的脚本语言。脚本写在一段文本里，用于骰点、角色卡属性公式、规则逻辑与插入原文的模板。

## 范围

语言规定词法与语句边界、值与类型、对象与函数、列表、骰点表达式、`Roll`、`Formula`、文本执行块、静态诊断与脚本值的序列化。

文中的 **必须** 表示实现符合本语言的必要条件，**应该** 表示推荐行为，**可以** 表示可选行为。

一个版本的标识符集合、运算符优先级、骰点词法与 `Roll` 值契约在版本内固定。解析器必须标明所实现的语言版本；同一段脚本在不同版本下不得被静默地按不同规则解释。

## 一段程序

```text
倍率 := 3
伤害(n) { n * 倍率 }

攻击 := d20 + 伤害(4)
攻击.total
```

一段程序由「语句」组成，语句以换行或 `;` 分隔；圆括号、方括号内的换行按空白处理。`x := expr` 声明名字，`x = expr` 给已存在的名字赋值，未声明的名字不能直接赋值。`x: Int := expr` 是带类型标注的声明。

每段代码取「最后一个表达式」的值。声明、赋值与 `while` 的结果是 `Unit`。`if` 是表达式，`while` 是语句：

```text
x := 12
判定 := if x >= 10 { "通过" } else { "未通过" }
判定
```

> **注意**
>
> 连续两个完整表达式不得仅靠空格分隔。`a := 1 b := 2` 是语法错误；写成两行或用 `;` 分隔。

## 执行块

文本里的 `{{ code }}` 是「执行块」。宿主在文本所在位置求值块内脚本，把最后一个表达式的值转成文字插回原位：

```text
调查员进行侦查：{{ 骰 := d100; if 骰 <= 75 { `成功（{骰.total}）` } else { `失败（{骰.total}）` } }}
角色生命值：{{ actor.HP }}
纯空结果不插入字符：{{ null }}
```

| 值 | 插入的文字 |
| --- | --- |
| `Int(0)`、`Float(0)` | `0`、`0.0` |
| `false` | `false` |
| 非空字符串 | 字符串本身 |
| 空字符串、`null`、`Unit` | 不插入文字 |
| `Roll` | 总值 |
| 列表、对象 | 稳定显示形式 |
| 带 `to_text()` 的对象 | `to_text()` 返回的 String |

`0` 与 `false` 必须正常显示；错误进入诊断通道，不得被当成空结果吞掉。

> **注意**
>
> 扫描执行块时必须按词法层级配对大括号。对象字面量与分支块里的 `}` 不结束执行块，简单匹配第一个 `}}` 会截断脚本。

## 脚本与输出

语言没有 `say`、`print`、`echo`，也没有输出语句。文本输出只有两条路径：执行块的返回值插回原文，反引号模板字符串里的 `{expr}` 求值为文字。

```text
名字 := "艾琳"
`角色 {名字}：体力 {actor.HP}`
```

脚本里的普通字段读取不产生随机抽样，也不触发公式求值；骰点表达式、显式 `.eval()` 与随机集合方法才消耗随机源。详见[骰点与 Roll](dice/)与[文本嵌入与渲染](text/)。
