「诊断」描述脚本里的一处错误或可疑写法。每条诊断至少包含稳定的 `code`、错误级别、可读短消息、UTF-8 源码的起止偏移与行列号、相关位置（例如声明处）以及可选的修复建议。

行列号从 1 开始，列按 Unicode 标量值计数；宿主转成编辑器所需的 UTF-16 偏移时保留同一位置。

## 诊断码

| 代码 | 类别 | 举例 |
| --- | --- | --- |
| `S001` | 词法错误 | 未闭合的引号或反引号模板 |
| `S002` | 语法错误 | 对象成员缺 `,`、多余的 `}` |
| `N001` | 未声明名字 | 写了 `力星 = 70`，声明的是 `力量` |
| `N002` | 重复声明 | 同一词法作用域出现两次 `x := ...` |
| `T001` | 类型不兼容 | `hp := 12; hp = "12"` |
| `T002` | 条件并非 `Bool` | `if 1 { ... }` |
| `C001` | 调用参数不合法 | `abs()`、`Int("abc")` |
| `O001` | 字段不存在 | 静态形状只有 `HP`，却读 `r.hp` |
| `D001` | 骰点语法错误 | `3d0`、无效修饰符、`3d6kh9` |
| `D002` | 骰点配置不允许 | 指定规则被禁用 |
| `F001` | 公式效果违规 | `formula(ctx => state.x = 1)` |
| `R001` | 运行资源耗尽 | 无限循环、过多骰子或爆骰轮次 |
| `P001` | 序列化失败 | 捕获了没有适配器的原生值 |
| `H001` | 渲染失败 | `to_text()` 有副作用或返回非 `String` |

诊断码在同一版本内固定；同一类错误在不同位置产生相同 `code`。

## 定位与建议

```text
1 | 力量 := 60
2 | 力星 = 70
    ^^^^
N001: 未声明的变量「力星」
  建议：你是否想使用第 1 行声明的「力量」？
```

```text
1 | r := { HP: 10, heal(n) { self.HP = self.HP + n; self.HP } }
2 | r.HP = "很多"
         ^^^^^^
T001: 不能将 String 赋给已知类型为 Int 的字段 HP
  建议：使用明确转换，或将字段声明为动态值。
```

```text
1 | 3d6kh9
    ^^^^^^^
D001: 保留的骰子数量 9 超过总骰数 3
```

规则骰即使成功解析，也把规则来源与参数位置写入 `Roll.trace`；运行时错误同样返回源码定位。执行块求值出错时进入诊断通道，不改成空字符串继续假装成功。

## 静态可识别的条件

分析器必须能静态识别：括号、字符串与模板闭合问题；名字是否已声明；基本参数个数；常量骰点的非法范围；可确定的类型冲突；静态形状里不存在的字段；纯骰点模式下的写操作。

> **注意**
>
> 无法静态获知的注入字段与 `Any` 值保留运行时检查，不制造虚假的静态保证。语法错误发生后，分析器恢复到下一处可识别的语句或对象成员分隔符，继续报告后续错误；错误恢复不得悄悄改动代码的解释。

关键字集合固定、骰点词法不依赖临时规则、对象方法与函数声明有明确的文法边界，因此同一段脚本在编辑器里的着色与静态诊断不随执行许可变化。文法边界见[文法与能力对照](../grammar/)。
