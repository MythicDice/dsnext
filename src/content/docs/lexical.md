源代码按 UTF-8 解释。「标识符」以 Unicode XID_Start 或 `_` 开头，续接 XID_Continue 或 `_`；`角色`、`hp_max` 合法，`3d6` 进入骰点词法而不是标识符。名字大小写敏感，标识符中的冒号不属于名字。

```text
角色 := { 侦查: 75 }
hp_max := 12
```

> **注意**
>
> 对仅 Unicode 规范化不同的标识符给出警告；建议源码统一采用 NFC。

## 注释与字符串

`#` 开始至行末为注释；字符串里的 `#` 是普通字符。单引号与双引号都是普通字符串，只处理反斜杠转义；反引号是带插值的模板字符串；`r"..."` 是「规则骰字面量」，不是原始字符串前缀。

```text
# 一行检定
骰 := d100
标题 := "侦查成功"
结果 := `点数 {骰.total}，{标题}`
奖励 := r"b2"
```

模板字符串用 `{expr}` 插值；`{...}` 内只能写一个表达式。字面花括号在模板里写成 `{{` 与 `}}`。插值采用与执行块相同的值转换规则，详见[文本嵌入与渲染](../text/)。

## 语句边界

| 位置 | 规则 |
| --- | --- |
| 顶层、函数体、控制流块 | 换行或 `;` 分隔语句 |
| 圆括号、方括号内 | 换行按空白处理 |
| 对象字面量 | 成员以 `,` 分隔，末尾逗号可写 |
| 未结束的运算表达式 | 可跨行书写 |

`:=` 是唯一的声明操作符，`=` 只对已存在的名字、可赋值字段、合法的列表下标与切片赋值。`x: Int = 1` 不合法。声明与赋值语句的值是 `Unit`。

## 表达式与块

`if` 是表达式；省略 `else` 且条件不成立时结果为 `Unit`。块取最后一个表达式的值，块内只有声明、赋值或循环时结果为 `Unit`。`while condition { ... }` 是语句，`break`、`continue` 只作用于最近的循环，`return` 退出最近的函数。

```text
检定(技能) {
    骰 := d100
    if 骰 <= 技能 { `成功（{骰.total}）` } else { `失败（{骰.total}）` }
}
检定(actor.侦查)
```

命名函数可带可选的参数与返回标注；匿名函数写成 `x => x + 1` 或 `(x, y) => x + y`，不带括号时只能有一个参数。

对象字面量只含 `key: expr` 与 `method(args) { ... }` 两种成员。`{...}` 在 `:=` 后是表达式语境，在 `if/while/函数` 后是块语境；块里要返回对象时写 `if ok { { x: 1 } }`。

## 骰点词法边界

`d20`、`3d6`、`2d20kh1` 精确匹配基础骰点模式；`d20foo` 是普通标识符，不会被拆开执行。`(n + 1)d(20)` 与 `n d 6` 使用中缀 `d`，表达式两端不是裸数词时以空格或括号区分。

`r"..."` 内部由规则骰子文法解释，`b2`、`f`、`4c3m7` 一类字符串不抢占主语言的标识符空间。规则骰只在 `r"..."` 与 `roll(String)` 的文法空间注册，不改变标识符解析。详见[骰点与 Roll](../dice/)。

## 运算符优先级

从高到低排列：

| 等级 | 语法 | 结合 | 含义 |
| --- | --- | --- | --- |
| 1 | `a.b`、`a[b]`、`a(...)`、`a[b:c]` | 左 | 成员、下标、调用、切片 |
| 2 | `NdM` 与 `kh/kl/dh/dl/min/max`、中缀 `d` | 左 | 创建 Roll |
| 3 | `**`、`^` | 右 | 乘方，`^` 为别名 |
| 4 | 单目 `+ - ! ~` | 右 | 正负、逻辑否、按位取反 |
| 5 | `* / %` | 左 | 乘除模 |
| 6 | `+ -` | 左 | 加减、同类串与列表连接 |
| 7 | `<< >>` | 左 | 整数位移 |
| 8 | `< <= > >=` | 不可链式 | 比较 |
| 9 | `== !=` | 不可链式 | 相等比较 |
| 10 | `&` | 左 | 按位与 |
| 11 | `|` | 左 | 按位或 |
| 12 | `&&` | 左 | Bool 短路与 |
| 13 | `\|\|` | 左 | Bool 短路或 |
| 14 | `??` | 右 | Null 合并 |
| 15 | `cond ? yes : no` | 右 | 条件表达式 |

赋值与声明不属于表达式优先级。位移只作用于 `Int`；`^` 已用作乘方别名，按位异或写成 `bitXor(a, b)`。`[a..b]` 是列表构造形式，`..` 不是通用中缀运算符。

## 类型标注

`Int`、`Float`、`Bool`、`String`、`Roll`、`Formula`、`List`、`Object`、`Any`、`Int?` 是可写的类型表达式。参数、局部变量与返回值均可省略标注；`List<Int>` 一类泛型写法不属于本版本。

```text
x: Int := 10
变化: Any := 12
可空值: Int? := null
```

类型与推断规则见[值与类型](../values/)。
