「公式」是延迟执行的计算。`formula(fn)` 接收一个可序列化的语言函数，返回 `Formula` 值；读取变量或对象字段只返回公式本身，调用 `.eval(ctx)` 才执行。

```text
攻击 := formula(ctx => d20 + ctx.加值)
人物 := { 加值: 4, 命中: 攻击 }

人物.命中                  # Formula，不抽样
人物.命中.eval(人物)        # 新一次随机计算，得到 Roll
人物.命中.eval(人物)        # 再算一次，独立样本
```

## eval 与 bind

`f.eval(ctx)` 的结果是公式返回的原始值，可为 `Int`、`Float`、`Bool`、`String`、`Roll`、`Object`，无值时为 `Unit`。`f.bind(obj)` 返回一个带默认上下文的新 `Formula`，不修改原公式；`.eval(explicit)` 里显式给出的字段覆盖绑定默认值。所有必需的 `ctx` 字段都已绑定时，`f.eval()` 才可省略参数，否则报缺少上下文属性。

```text
伤害 := formula(ctx => 2d6 + ctx.力量)
固定 := 伤害.bind({ 力量: 4 })
固定.eval()                # 2d6 + 4
固定.eval({ 力量: 8 })      # 2d6 + 8
```

## 效果限制

公式体允许读取 `ctx`、读取捕获的不变常量、调用纯函数与随机抽样；禁止赋值、对象变更、持久状态写入、外部输入输出与效果未声明的函数调用。静态检查覆盖可判定的部分，求值时再次执行效果校验。

捕获可变对象时，公式封入其只读快照，不持有指向可变状态的隐式引用。公式对象本身可序列化，恢复后不提前求值。

| 操作 | 是否抽样 |
| --- | --- |
| 读取 `人物.命中` | 否 |
| 序列化与反序列化公式 | 否 |
| `f.bind(obj)` | 否 |
| `f.eval(ctx)` | 是，每次独立 |

> **注意**
>
> 公式字段与普通函数字段的区别只在求值时机。写在对象里的普通函数仍然按调用求值，读取字段不会触发任何计算；要显式延迟计算就用 `formula(fn)`。

`Formula` 取代旧 computed 的能力，但不复制「读取即执行」的隐式语义；读取路径、`.eval(ctx)` 与 `.bind()` 共同构成显式的延迟计算。能力对照见[文法与能力对照](../grammar/)。
