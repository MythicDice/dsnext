「抽样」与「引用」分离：每个骰点表达式求值时抽样一次，结果保存之后，读取变量、字段、数组元素或把结果参与计算都不再抽样。只有重新求值骰点表达式、调用规则骰函数或显式 `.eval()` 才抽样。

```text
r := d6
r + r                    # 同一次样本值加两遍
[d6, d6].sum()            # 两次独立样本
```

## 普通骰点

| 语法 | 含义 |
| --- | --- |
| `d20` | 1 枚 20 面骰 |
| `3d6` | 3 枚 6 面骰，默认加和 |
| `(等级 + 1)d(20)` | 骰数与面数在运行时计算 |
| `2d20kh1`、`2d20k1` | 保留最高 1 枚 |
| `2d20kl1`、`2d20q1` | 保留最低 1 枚 |
| `4d6dl1`、`4d6dh1` | 丢弃最低／最高 1 枚 |
| `3d20min10`、`3d20max15` | 每枚骰的下限／上限 |
| `d20优势`、`d20劣势` | `2d20kh1`／`2d20kl1` |

修饰符只作用于骰点结果的骰子集合，顺序固定为 `min`／`max` 截断 → `kh`／`kl`／`dh`／`dl` 筛选 → 汇总。同一类筛选修饰符不能连用两次，`d20优势` 不与取高取低修饰连用。`0d6`、`d0`、`1d6kh2` 一类不合法的数量在静态可知时提前诊断。

基础骰点模式精确匹配；`d20foo` 是标识符，`a2`、`b2`、`f` 一类规则写法不进入普通标识符词法空间。

## 规则骰空间

`r"..."` 在独立的「规则骰文法」里解析并立即求值，结果为 `Roll`：

```text
奖励 := r"b2"            # CoC 奖励骰
惩罚 := r"p1"            # CoC 惩罚骰
命运 := r"f"             # Fate
成功数 := r"5a9k2"       # WoD 成功数
爆骰 := r"4c3m7"         # Double Cross
```

`roll(text: String)` 按字符串动态选择规则骰语法，返回 `Roll`；参数必须是 `String`，传 `Roll` 报类型错误。`coc.bonus(n)`、`coc.penalty(n)`、`fate.roll()`、`wod.roll(count, again, target)` 是常见规则的等价入口。规则骰的解析、结果语义与所选规则配置一致，返回标准的 `Roll`。

## Roll 的值契约

```text
一次 := 4d6kh3
一次.total      # Int 或 Float，总值
一次.faces      # List<Int>，按抽样顺序展平的原始骰面
一次.dice       # List<Object>，每枚骰的 raw、effective、kept、round
一次.trace      # 结构化的计算树
一次.detail     # 可读的计算过程文本
```

`faces` 是原始面值，不反映 `min`／`max` 截断；有效值读 `dice[i].effective`，保留与否读 `dice[i].kept`，多轮骰点的轮次读 `dice[i].round`（从 1 开始）。`trace` 为每个抽样节点保留独立身份，可据此区分「同一结果被引用两次」与「独立抽了两次」。

| 运算 | 结果 |
| --- | --- |
| `Roll + Int/Float/Roll` 等四则与乘方 | 带计算轨迹的 `Roll` |
| `Roll` 与数值比较 | 按 `.total` 比较，返回 `Bool` |
| `Int(roll)`、`Float(roll)` | 纯数值，丢弃轨迹 |
| 反引号模板插值 | 按总值转为文字 |
| `roll + "伤害"` | 类型错误 |

> **注意**
>
> `Roll.total` 不一定是骰面之和：WoD 表示成功数，Double Cross 按轮数规则结算。不要重新统计 `.faces` 来推断 `.total`。

默认文字展示取最终值；要显示完整过程显式读 `.detail`。`Roll + 2` 仍是 `Roll`，多次读取同一变量不产生新的随机数。

## 随机源与限额

骰点抽样与集合的随机方法共用同一个可注入、可种子复现的随机源。求值受骰数、骰面范围、爆骰轮次、操作次数、递归深度、分配、字符串长度与序列化大小的共同约束；限额耗尽报错，不静默截断结果。`Roll` 按保留抽样身份的结构化数据序列化，不退化成 `.detail` 字符串。

延迟计算见[延迟公式](../formula/)；资源与序列化条款见[文本嵌入与渲染](../text/)。
