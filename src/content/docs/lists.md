「列表」是可变有序集合，下标从零开始；元素类型可以混合，静态检查只覆盖能确定的用法。

```text
数组 := [1, 2, 3]
区间 := [1..5]              # [1, 2, 3, 4, 5]
倒序 := [5..3]              # [5, 4, 3]
重复 := [x] * 3
```

`[a..b]` 是包含两端的闭区间，反向区间同样合法。`[x] * n` 重复元素；元素为对象时复制的是引用，列表里的多个位置指向同一对象身份。

## 下标与切片

`a[i:j]` 是右边界不包含的半开切片；负索引从末尾计数；越界报错。`a[i:j] = values` 用另一个列表替换一段连续元素。

```text
数组 := [1..5]
数组[1:3] = [8, 9]          # [1, 8, 9, 4, 5]
数组[1:3]                   # [8, 9]
数组[-1]                    # 5
```

字符串下标与切片按 Unicode 标量值计数，不按 UTF-8 字节计数。`[a..b]` 只用于列表构造，`..` 不是通用中缀运算符。

## 集合方法

| 方法 | 效果 |
| --- | --- |
| `a.len()`、`a.length` | 长度 `Int` |
| `a.sum()` | 数值求和；含 `Roll` 时保留计算轨迹 |
| `a.kh(n=1)`、`a.kl(n=1)` | 取最高／最低 n 项后按值求和，不改变 `a` |
| `a.shuffle()` | 返回随机重排的新列表，不改变 `a` |
| `a.rand()` | 随机取一项，不改变列表 |
| `a.randSize(n)` | 不放回随机取 n 项，不改变列表 |
| `a.push(x)` | 在尾部追加，修改并返回 `a` |
| `a.pop()`、`a.shift()` | 移除末尾／首项，返回被移除的值 |
| `a.map(f)` | 返回逐项映射的新列表 |
| `a.filter(f)`、`a.count(f)` | `f` 必须返回 `Bool`；返回新列表或项数 |

`kh`、`kl` 可处理 `Int`、`Float`、`Roll` 项；排序按数值比较，`Roll` 取 `.total`，相等时以原始索引稳定决胜。`n` 必须在 `[1, a.len()]` 内。空列表的 `sum()` 是 `Int(0)`，空列表的 `rand()`、`pop()`、`shift()` 报错。

```text
骰 := 5d10
成功数 := 骰.faces.count(x => x >= 8)
`成功数 {成功数}，骰面 {骰.faces}`
```

> **注意**
>
> `r.faces` 是原始骰面，被舍弃的骰子仍在内。只要保留的骰面时写 `r.dice.filter(x => x.kept).map(x => x.effective)`。

`shuffle`、`rand`、`randSize` 消耗随机源；`sum`、`kh`、`kl`、`map`、`filter`、`count` 不抽样。完整内建方法表见[内建函数](../builtins/)。
