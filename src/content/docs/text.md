脚本写在宿主文本里时，`{{ code }}` 标记一个「执行块」。块内是一段完整脚本，最后一个表达式的值转成文字插回原位；多个执行块按文本顺序求值，共享同一环境与随机源。块内 `:=` 的局部绑定不会自动成为下一个块的全局名字。

```text
调查员侦查：{{ 骰 := d100; if 骰 <= actor.侦查 { `成功 {骰.total}` } else { `失败 {骰.total}` } }}
角色生命值：{{ actor.HP }}
纯空结果不插入任何字符：{{ null }}
```

## 值到文字的转换

| 值 | 插入的文字 |
| --- | --- |
| `Int(0)`、`Float(0)` | `0`、`0.0` |
| `false` | `false` |
| 非空字符串 | 字符串本身 |
| 空字符串、`null`、`Unit` | 不插入文字 |
| `Roll` | 总值 |
| 列表、对象 | 稳定显示形式 |
| 带 `to_text()` 的对象 | `to_text()` 返回的 String |

`to_text()` 只能做确定性的无副作用计算，不可抽样、改状态或调用有外部效果的方法；它只在渲染边界被调用，普通读取、比较与赋值都不触发。渲染失败报诊断，不得悄悄当作 `null`。

> **注意**
>
> `0` 与 `false` 必须正常显示。只有 `null`、`Unit` 与空字符串产生空替换，错误不得被吞成空结果。

## 模板插值

反引号字符串用 `{expr}` 插值，普通单双引号不插值。插值内容是单个表达式，不能声明变量或写多条语句；复杂逻辑先写成函数或放进执行块。模板里的字面花括号写作 `{{` 与 `}}`。

```text
名字 := "艾琳"
文本 := `角色 {名字}：体力 {actor.HP}`
```

执行块扫描与模板扫描是两个独立上下文：先按词法层级确定 `{{...}}` 的边界，块内的反引号字符串再交给脚本词法解释。

## 注入变量

`actor`、`state`、`coc`、`fate`、`wod`、`dx` 是约定名字的注入值，不是关键字。`actor` 是当前人物卡，`state` 是持久状态字典，`coc` 等是规则骰函数对象。动态字段用 `actor.get("力量", 0)` 取带默认值的属性；直接读取不存在的 `actor.力量` 报属性不存在。

## 执行模式

同一套语法有两种执行许可：

| 模式 | 允许 |
| --- | --- |
| 完整规则模式 | 普通函数、对象、限额内的循环、允许写的状态赋值 |
| 纯骰点模式 | 算术、骰点、纯方法求值 |

纯骰点模式禁止声明、赋值、`while`、持久写入与非纯调用；被禁止的写法明确报诊断。执行许可不改变词法结果，同一段合法表达式在两种模式下的解释一致。

## 序列化契约

可持久化的脚本值包括 `Null`、`Bool`、`Int`、`Float`、`String`、`List`、`Object`、`Roll`、`Formula`、脚本 `Function` 与已绑定接收者的方法值。编码保存值类型、对象引用身份、别名与循环引用、函数体与自由变量、公式绑定值、`Roll` 的结构化轨迹，并带上独立的格式版本。

序列化与反序列化不调用 `to_text()`、对象方法或 `.eval()`；保存 `Roll` 不重新抽样，恢复 `Formula` 不提前求值。对象引用按带身份标记的引用图编码，恢复后保留共享引用与循环引用。没有可恢复适配器的原生值报序列化失败，不伪造数据。持久化函数保留其静态语义版本，版本不兼容时报迁移错误。

## 预算

读取普通属性、字段、数组元素没有隐藏副作用；`get`、`has` 不抽样；显式 `.eval()`、骰点表达式与随机集合方法才消耗随机源。指令数、递归深度、骰数、骰面、爆骰轮次、内存、字符串长度与序列化大小都计入限额，超限报诊断。文件系统、网络、定时器与异步不在脚本语言的标准能力内。

骰点预算条款见[骰点与 Roll](../dice/)；诊断的数据格式见[静态诊断](../diagnostics/)。
