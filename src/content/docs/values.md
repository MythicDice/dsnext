脚本值分为「数值」「文本」「集合」「可调用值」「领域值」五类。局部变量在声明时从表达式推断类型；推断不出的形参与动态字段按 `Any` 在运行时检查。

```text
hp := 12
标题 := "探索"
骰 := d20
列表 := [1, 2, 3]
变化: Any := 12
变化 = "未知"
可空值: Int? := null
可空值 = 8
```

推断得到的绑定类型是约束。给 `hp` 赋 `"12"` 是类型错误，赋 `Int("12")` 合法。写成 `Any` 的绑定允许换成其他类型；标注为 `Any` 不等于静态证明安全。

## 内建类型

| 类型 | 取值与规则 |
| --- | --- |
| `Int` | 有符号 64 位整数；溢出报错 |
| `Float` | 有限 IEEE-754 binary64；产生非有限数时报错 |
| `Bool` | `true`、`false`；不是 `Int` 的别名 |
| `String` | Unicode 字符串；下标与切片按 Unicode 标量值计数 |
| `Null` | `null`，用于缺失与可空值 |
| `Unit` | 无结果；赋值、声明、`while` 的值 |
| `List` | 可变有序集合，允许混合元素 |
| `Object` | String 键到字段与方法的可变映射 |
| `Function` | 带词法环境的可调用值 |
| `Roll` | 已结算的一次随机计算，带数值与过程 |
| `Formula` | 延迟计算，显式 `.eval()` 才执行 |
| `Any` | 类型检查上的动态边界 |

`Null` 与 `Unit` 不可互换；对象不存在类、接口、原型与继承，详见[对象、函数与作用域](../objects/)。

## 显式转换

```text
Int("12")        # 12
Int(3.9)         # 3，朝零截断
Float("3.5")     # 3.5
Bool(0)          # false
Bool("ok")       # true
String(123)      # "123"
```

`Int`、`Float`、`String`、`Bool` 是显式转换函数，失败报错。`Int(roll)` 与 `Float(roll)` 取 `Roll` 的数值并丢弃计算轨迹；字符串不自动转数字，`Roll` 也不自动转成纯数值。

## 数值与逻辑

`Int + Float` 提升为 `Float`，`Int / Int` 得到 `Float`，`%` 只作用于 `Int`，`**` 与 `^` 是乘方。整数与浮点在可解释范围内比较，不自动把数字转成字符串。

条件和逻辑运算不隐式应用 `Bool`；`if 1 { ... }` 是类型错误，`if Bool(1) { ... }` 合法。`&&`、`||` 短路并返回 `Bool`，`??` 只在左侧为 `null` 时取右侧，三元表达式的条件要求是 `Bool`。

```text
0 ?? 2           # Int(0)
null ?? 2        # Int(2)
false || true    # Bool(true)
if false { 7 }   # Unit
```

> **注意**
>
> `??` 只合并 `null`，不合并 `false` 与 `0`。`Bool(x)` 对未知类型的对象需要显式转换，不能把对象直接当条件。

`Roll` 在数值运算与比较中按 `.total` 参与，运算结果仍保留计算轨迹；两个 `Roll` 比较数值，不比较轨迹。详见[骰点与 Roll](../dice/)。
