「对象」是 String 键到字段与方法的可变映射。对象字面量只有 `key: expr` 与 `method(args) { ... }` 两种成员，以逗号分隔，末尾逗号可写：

```text
角色 := {
    名称: "战士",
    HP: 12,
    护甲: 2,
    受伤(n) {
        self.HP = max(0, self.HP - max(0, n - self.护甲))
        self.HP
    },
}

角色.受伤(5)
角色["HP"]
角色.职业 = "战士"
```

## 字段与方法

每次求值 `{...}` 都构造一个新的对象身份。对象赋值与传参传递引用；数字、字符串按值语义。`obj.a` 与 `obj["a"]` 读取同一字段，不存在隐藏的父类查找或 getter 自动求值；所有键都是 String，`12` 与 `"12"` 不是同一个键。

读取不存在的字段报错；`obj.get("a", default)` 取带默认值的字段，`obj.has("a")` 返回 `Bool`。显式赋值可覆盖或添加字段；对静态形状已知的对象，疑似拼错的新字段给出警告。

方法成员用 `self` 绑定接收者。提取方法值时接收者绑定保留在可调用值里：

```text
o := { HP: 8, heal(n) { self.HP = self.HP + n; self.HP } }
f := o.heal
f(2)
o.HP                 # Int(10)
```

> **注意**
>
> 只有 `m(args) { ... }` 形式的方法获得 `self`。写成 `f: x => x + 1` 的普通函数值不会因存放在对象里而变成方法，调用语义不随存放位置变化。

## 函数与闭包

```text
倍率 := 3
加成 := n => n * 倍率
加成(5)                      # 15

阶乘(n: Int) -> Int {
    if n <= 1 { 1 } else { n * 阶乘(n - 1) }
}
```

参数标注与返回标注都可选，命名函数可自递归。每次调用创建独立的局部词法绑定，闭包可捕获外层变量；`return expr` 提前结束函数，未显式返回时取最后一个表达式的值。多语句匿名函数写成 `(x, y) => { ... }`。

## 词法作用域

```text
x := 1
if true {
    y := 2
    x = 3
}
x                  # 3
y                  # 错误，不在作用域
```

作用域按词法规则划分。控制流块内声明只在该块有效，对外层已有名字的赋值修改外层绑定。同一层不能重复声明；内层同名遮蔽允许但给出警告。持久状态写在 `state` 对象的字段里，不通过未声明的全局赋值创建。

## 控制流

`if` 是表达式，`while` 是语句并返回 `Unit`，`break`、`continue` 只作用于最近的循环。条件必须是 `Bool`。

```text
i := 0
总数 := 0
while i < 5 {
    总数 = 总数 + i
    i = i + 1
}
总数
```

> **注意**
>
> `while` 结果不参与表达式求值；要得到循环累计值，把值保存在外层变量里，或在循环后写独立的表达式。
